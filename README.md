# Country-Product Dependency Dashboard

Interactive dashboard for exploring country-level trade networks by product,
supplier importance, and network-adjusted import exposure.

- [Open the dashboard](https://asjadnaqvi.github.io/dependency/)
- [Dashboard guide](dependency/README.md)

Trade data: BACI HS22 2024. Country-risk weighting uses 2024 Political
Stability scores from the World Bank's WGI 2026 release. See the guide for
data definitions and control descriptions.
