# Dependency Dashboard

Static GitHub Pages dashboard for country-product dependency analysis.

This app displays a product network, dependency heatmaps, and summary tables using precomputed data stored in the data folder.

## Local preview

From the repo root, run:

python -m http.server 8000

Then open:

http://localhost:8000/dependency/

## Deployment

This project is configured for GitHub Pages deployment from the dependency folder.
